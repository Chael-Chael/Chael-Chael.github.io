Interactive ASCII Particle Logo

TL;DR. Use a full-screen near-black stage, one centered luminous identity mark, and no competing interface. Let motion scatter locally, then settle back into a precise silhouette.

Patterns

  1. Give the identity the whole stage. Remove navigation, cards, and competing copy from the first viewport.
  2. Keep atmosphere subordinate. Use only a faint blue-black field; the brightest pixels stay inside the MAIR mark.
  3. Make motion spatially meaningful. Particles should return to a stable anchor instead of drifting forever.
  4. Preserve the source color. Retain MAIR's blue-to-cyan gradient rather than reducing it to generic white ASCII.

Proposed composition

+------------------------------------------------------+
|                                                      |
|                 .+%#@ MAIR @#%+.                    |
|             pointer scatters nearby glyphs           |
|                 spring returns them                  |
|                                                      |
+------------------------------------------------------+

Applied constraints

  • No third-party rendering or physics library.
  • Transparent image bounds cropped before responsive grid sampling.
  • Local blue/cyan source color retained per cell.
  • Temporary pointer repulsion with spring-damper return.
  • A stable reduced-motion treatment.
